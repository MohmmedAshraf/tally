`schemas/*.json` are generated from the Zod schemas and shipped with the package for adapters written in other languages:

```ts
import queryRequest from 'tally-protocol/schemas/query-request.json' with { type: 'json' }
```

`toJsonSchema(name)` returns the same document at runtime.
