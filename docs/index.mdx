Tally is the data grid with a query language, saved views and a backend protocol. Typed columns, grouping, live rows, undo, cards on phones, AI that writes real queries, and an MCP server so your coding agent knows where every change goes.

The engine lives in `tally-core` and knows nothing about the DOM. `tally-react` renders it as a full component, and `tally-vue`, `tally-svelte` and `tally-solid` bind it to their frameworks. Rows come from an array, from any server that speaks the Tally Query Protocol, or from an adapter for TanStack Query, TanStack DB or Supabase.
